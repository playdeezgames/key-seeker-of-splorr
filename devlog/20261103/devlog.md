# Key Seeker of SPLORR!! now runs in the browser

The 2023 ASCII Game Jam game was a terminal program that only ran as a download. It is now a web page as well: a straight port of the VB.NET original to Odin and WebAssembly.

What carried over: the mazes for the town, the forest, the sewer, the ruins and the UFO, the grid graveyard and the seven-storey tower, the five keys, the shops, the dice that only count on a six, the gear that wears out and breaks, and the lever at the end. The original's oddities are kept on purpose; the list is in QUIRKS.md in the repo.

What changed: the Spectre.Console menus are click, tap, number-key or arrow-key menus; the game saves itself in the browser's local storage after every turn, so closing the tab does not lose your place; there is no Quit (it is a tab now); and picking something up now says what you took, where the original wiped the line off the screen straight away.

The port was written with Claude Code at my direction, and the original's rules were read from its source, not guessed. The downloads are still here and are still the original.
